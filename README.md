# 03.KPdash README

## 이 폴더의 역할
KP/Thekary 대시보드 데이터, 화면 코드, 리포트 export, 운영 문서를 관리한다.

## 기준 문서
- 작업 문서: `034.docs/README.md`
- 주요 참고 문서: `034.docs/`

## 폴더 맵
- `031.data`: 원본/정규화 데이터, 반영 대상 데이터셋
- `032.dashboard`: 실제 대시보드 앱/코드
- `033.export`: PDF, PPT, 스크린샷, 보고용 산출물
- `034.docs`: 지표 정의, 운영 기준, 반영 절차

## 기본 작업 순서
1. 요청 월/기간, 브랜드, 수정 범위를 확인한다.
2. `031.data`와 Google Sheets/Supabase 등 원천 데이터를 확인한다.
3. `032.dashboard`에서 대시보드 코드나 데이터 반영을 수행한다.
4. 빌드/브라우저/스크린샷 기준으로 수치와 레이아웃을 QA한다.
5. 최종 export를 `033.export`에 저장한다.
6. 지표 정의나 반복 규칙이 바뀌면 `034.docs`, `README.md`, 관련 skill/runbook을 갱신한다.

## 완료 기준
- 데이터 출처와 반영 범위가 명확함
- 화면 QA 또는 export QA가 끝남
- 최종 결과물이 `033.export`에 저장됨
